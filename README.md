# المحطة — مشوارك بقى أسهل · حزمة النشر

## إصلاحات ٢٢ أكتوبر ٢٠٢٦ (بعد محاكاة ٥×٥ و٣×١٠ و١٠×٣)
- راكبين بيختاروا نفس السائق في نفس اللحظة ← واحد بس بياخده.
- السائق اللي ساب مشوار مابيشوفوش تاني، ومايقدرش يسيبه بعد ما الراكب يركب.
- لما الراكب يلغي، السائق بيتقاله «الراكب لغى الطلب» (مش «اختار سائق تاني»).
- زرار «وافق» بيرجع يشتغل لما الطلب يرجع بعد «الراكب ماردّش».
- الطلب اللي بيرجع للسواقين بياخد ١٠ دقايق جديدة.
- الراكب اللي مستني ٥ دقايق أو أكتر (في حدود ٢ كم) بيطلع أول القايمة عند السائق، ومكتوب عليه «مستني من X دقايق».

## الجديد في النسخة دي

| الميزة | فين |
|---|---|
| **كود الركوب:** الراكب بيشوف ٤ أرقام، والسائق لازم يكتبهم علشان يبدأ الرحلة | `index.html` + `driver.html` + `/api/driver/start` |
| **شارك رحلتك:** لينك واتساب للأهل يتابعوا بيه الرحلة، من غير أي أرقام تليفونات | `track.html` + `/api/share` |
| **بلاغ «طلب أكتر من السعر»** وبلاغات تانية، بتوصل تبويب «البلاغات» في الإدارة | `/api/report` + `admin.html` |
| **مشاويرك بدوسة واحدة:** آخر مشاوير الراكب بتظهر فوق الخريطة، واسمه ورقمه محفوظين | `index.html` (على موبايل الراكب بس) |
| **طلب بالتليفون:** الإدارة تدخّل الطلب لحد معندوش سمارت فون | `admin.html` + `/api/phone-request` |
| **تنبيه السائق:** صوت واهتزاز وإشعار، والشاشة تفضل منوّرة | `driver.html` + `sw.js` |
| **يتثبّت كتطبيق:** أيقونة على الشاشة الرئيسية للراكب والسائق، من غير Google Play | `manifest*.webmanifest` |
| **مجاني أول ٦ شهور، وبعدين اشتراك أسبوعي (٣٠ ج) أو شهري (١٠٠ ج):** من الإدارة ← تبويب الإدارة ← «بعد ٦ شهور» ← حفظ. لما السائق يدفع كاش، تدوس «+ أسبوع» أو «+ شهر» جنب اسمه. لو اشتراكه خلص بياخد مهلة ٣ أيام، وبعدها الطلبات بتوقف لحد ما يجدّد | `functions/api` + `admin.html` + `driver.html` |
| **تقييم السائق:** نجوم بعد الرحلة، ومتوسط كل سائق بيظهر في الإدارة | `index.html` + `/api/rate` + `admin.html` |
| **تقييم واحد بس لكل راكب:** كل رقم موبايل يقيّم نفس السائق مرة واحدة، حتى لو ركب معاه كذا مرة | `/api/rate` + `/api/track` |
| **حساب السائق مربوط بموبايل واحد:** أي موبايل تاني يحاول يدخل، بيظهرلك في الإدارة ← السائقون ← «وافق / ارفض» | `/api/driver/login` + `admin.html` |
| **«السائق مش هو اللي في الصورة»:** الحساب بيتوقف مؤقتاً على طول، و٣ بلاغات من ٣ ركاب مختلفين بتوقفه نهائياً. البلاغ متاح لحد ساعة بعد الرحلة بس | `index.html` + `/api/report` + `admin.html` |
| **رقم السائق ظاهر للراكب:** في شاشة «جاي ليك»، وبعد الرحلة («نسيت حاجة؟ اتصل بالسائق»)، وفي «رحلاتي». رقم الراكب لسه مابيظهرش للسائق | `index.html` + `me.html` + `/api/track` |

**لسه متعملوش:** كود الدعوة، والتقرير الأسبوعي على واتساب. الباقات اتشالت لأن التطبيق بقى مجاني.

> لو كنت منزّل النسخة القديمة قبل كده: **مش محتاج تمسح قاعدة البيانات.** انشر الملفات الجديدة بس (`wrangler pages deploy .`). الطلبات القديمة مالهاش كود، فهتخلص عادي من غير ما السائق يكتب كود.

# توكتوك كفر صقر — حزمة النشر

تطبيق ويب كامل لتشغيل توكتوك في **مدينة كفر صقر** بنموذج:
**سعر ثابت منشور + سباق قبول** — الطلب يوصل لكل السواقين الأونلاين، وأول واحد يضغط «خد المشوار» ياخده. مفيش مرسال يوزّع، ومفيش مفاصلة.

التكلفة: **صفر جنيه.** كل حاجة على الطبقة المجانية في Cloudflare، والخرائط من OpenStreetMap.

---

## الصفحات الثلاثة

| الصفحة | لمين | الحماية |
|---|---|---|
| `/` | الراكب — يحط دبوسين على الخريطة، يشوف السعر، يطلب، ويتابع السائق | مفتوحة |
| `/driver.html` | السائق — يستقبل الطلبات ويسابق عليها | رقم موبايله + كود من الإدارة |
| `/admin.html` | إنت — السائقين، المناطق، النقاط، المتابعة | رقم سرّي |

## خطوات النشر (٣٠–٤٠ دقيقة، مرة واحدة بس)

### ١. حساب Cloudflare
افتح <https://dash.cloudflare.com/sign-up> واعمل حساب مجاني. مش محتاج كارت ائتمان.

### ٢. ثبّت أداة Wrangler
محتاج Node.js على الجهاز. بعدين من الـ Terminal:

```bash
npm install -g wrangler
wrangler login
```

### ٣. اعمل قاعدة البيانات

```bash
wrangler d1 create toktok-kafrsaqr
```

هيطبعلك سطور فيها `database_id`. **انسخ الـ id ده.**

### ٤. اعمل ملف `wrangler.toml`
جوه فولدر المشروع، اعمل ملف اسمه `wrangler.toml` وحط فيه:

```toml
name = "toktok-kafrsaqr"
pages_build_output_dir = "."
compatibility_date = "2026-01-01"

[[d1_databases]]
binding = "DB"
database_name = "toktok-kafrsaqr"
database_id = "حط-الـ-id-اللي-نسخته-هنا"
```

### ٥. جهّز الجداول والبيانات المبدئية

```bash
wrangler d1 execute toktok-kafrsaqr --remote --file=./schema.sql
wrangler d1 execute toktok-kafrsaqr --remote --file=./seed.sql
```

`seed.sql` بيحط ٧ مناطق و٢٤ نقطة ركوب في المدينة، وسعر ١٥/٢٠.

### ٦. انشر

```bash
wrangler pages deploy .
```

هيديك رابط زي `https://toktok-kafrsaqr.pages.dev` — ده موقعك، ومجاني للأبد.

### ٧. اضبط الرقم السرّي للإدارة

```bash
wrangler pages secret put ADMIN_PIN --project-name toktok-kafrsaqr
```

هيسألك تكتب الرقم. **اختار رقم مش سهل، ومتكتبوش في أي مكان عام.**

> لو الأمر ده مشتغلش، تقدر تضبطه من الموقع:
> Cloudflare Dashboard ← Workers & Pages ← مشروعك ← Settings ← Variables and Secrets ← Add ← نوعه **Secret** ← الاسم `ADMIN_PIN`.
> لازم تعمل `wrangler pages deploy .` تاني بعد ما تضيفه.

---

## أول تشغيل

1. افتح `رابطك/admin.html` وادخل بالرقم السرّي.
2. **نقاط الركوب** ← اختار نقطة ← «حدّد على الخريطة» ← دوس مكانها. كرّر للـ ٢٤ نقطة. *(ده أهم خطوة — من غير إحداثيات، تحديد المنطقة والسعر مش هيشتغل صح.)*
3. **السائقون** ← ضيف كل سائق بلوحته ورخصته. التطبيق بيولّد له كود ٤ أرقام.
4. دوس **«ابعتله الكود»** — بيفتح واتساب برسالة جاهزة فيها الكود ورابط تطبيق السائق.
5. ابعت الرابط الرئيسي للركاب.

---

## إزاي سباق القبول بيشتغل

1. الراكب يبعت طلب → الحالة `pending`.
2. كل سائق أونلاين بيشوف الطلب خلال ٤ ثواني (بدون اسم أو رقم الراكب).
3. أول واحد يضغط «خد المشوار» يكسب. الباقي يشوفوا «سائق تاني خد المشوار».
4. الفايز بس هو اللي بيشوف اسم ورقم الراكب.
5. الراكب بيشوف اسم السائق ولوحته ورقمه على طول.

**القبول ذرّي على مستوى قاعدة البيانات** (شرط `status='pending'` جوه جملة الـ UPDATE نفسها)، يعني مستحيل سائقين اتنين ياخدوا نفس المشوار حتى لو ضغطوا في نفس اللحظة.

## حدود لازم تعرفها

**مفيش إشعارات Push.** دي صفحة ويب، فالسائق لازم يسيب الصفحة مفتوحة علشان يشوف الطلبات. للتجربة — سواقين قاعدين على الموقف والموبايل في إيدهم — ده شغال. الإشعارات الحقيقية محتاجة تطبيق أندرويد أصلي.

**دخول السائق بسيط** (موبايل + كود ٤ أرقام). مناسب لعشرين سائق كلهم معروفين بالاسم، مش مناسب لو كبرت.

**الاستضافة بره مصر.** قانون حماية البيانات ١٥١/٢٠٢٠ مع الإنفاذ الكامل من **٣١ أكتوبر ٢٠٢٦** بيدفع ناحية استضافة جوه مصر. للتجربة بعشرين سائق ده مقبول كبداية، لكن قبل ما تكبر لازم تراجعه مع محامي.

**الأسعار لسه مبدئية.** راجع تعريفة التوكتوك المعتمدة من محافظ الشرقية (قانون المرور ١٧/٢٠٢٤) قبل ما تثبّت ١٥/٢٠.

## تأكيد رقم الراكب بكود على واتساب (اختياري)
- للراكب بس: أول ما يفتح التطبيق، وبعدها كل ١٨٠ يوم. السائق بيدخل بالكود اللي بتديهوله الإدارة.
- من غير الإعدادات دي، التطبيق بيشتغل عادي، والتأكيد بيعدّي لوحده.
- Cloudflare ← Pages ← el-mahatta ← Settings ← Variables and Secrets، وضيف:
  - `WA_TOKEN`: توكن دائم من Meta (System User)، واختار **Encrypt**.
  - `WA_PHONE_ID`: الـ Phone number ID بتاع رقم واتساب بيزنس.
  - `WA_TEMPLATE` (اختياري): اسم قالب الـ Authentication. الافتراضي `mahatta_otp`، واللغة Arabic.
- بعدها اعمل Retry deployment.
- حدود الأمان: كود كل دقيقة، و٥ أكواد للرقم في اليوم، و٥ محاولات للكود، والكود بيخلص بعد ١٠ دقايق.


## رسايل ومكالمات بالنت بين الراكب والسائق
- رقم الراكب مش بيظهر للسائق خالص. الإدارة بس هي اللي بتشوفه.
- الرسايل شغالة طول ما المشوار شغال، ونص ساعة بعد ما يخلص.
- المكالمة صوت بالنت، شغالة من غير أي إعداد.
- لو مكالمات كتير مااتوصلتش (بتحصل على بعض شبكات الموبايل)، فعّل Cloudflare TURN: من Cloudflare ← Realtime ← TURN ← Create key، وضيف `TURN_KEY_ID` و`TURN_KEY_TOKEN` (Encrypt) في متغيرات المشروع، وبعدين اعمل Retry deployment.


## الخريطة لايف والمسار
- السائق بيبعت مكانه كل ٥ ثواني وهو في مشوار بس. أول ما المشوار يخلص، بيبطّل.
- الراكب بيشوف السائق بيتحرك على الخريطة، والمسار على الطرق، و«هيوصلك خلال … دقيقة». وبعد ما يركب، المسار بيتغيّر للوجهة.
- المسار من OSRM (مجاني، من غير مفتاح). لو الخدمة وقعت، بيظهر خط مستقيم والوقت تقريبي.
